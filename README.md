# TizWildin-Skyline

Neon-first synthwave loop pack with a darker second half, preserved in the same single-folder layout as the on-disk pack.

## Included
- 30 stereo WAV loops in `loops/`
- Ableton `.asd` analysis sidecars preserved with the current pack state
- `loops/README.txt` original pack notes
- `loops/generate_pack.py` generator snapshot

## Format
- 44.1 kHz
- 16-bit PCM WAV
- stereo

## Character split
- `01`-`20`: brighter neon / arcade / prism / rush material
- `21`-`30`: darker additions with more void, ghost, and noir energy

## Structure
- `loops/` full pack contents and generator snapshot
- `pack_manifest.json` machine-readable loop inventory for the repo

This repo mirrors the on-disk pack layout while keeping a clean top-level README for browsing.
